# Project
## Martinez_DLBCL_2012
Ordinary differential equation model of gene regulatory network (GRN) involved in Plasma cell differentiation as described in Martinez,2012.
The script contains Healthy and several diseased versions of the network, also described in Martinez,2012, namely: M1,M2,M3A,M3B,M8,M2M8.
M2,M8 and M2M8 are run by using the corresponding set of parameters with the Healthy version of GRN.
M1,M3A and M3B are run by using the Healthy set of parameters with the corresponding set of GRN.
Still need to implement M4-7 models.

##Software
All software is written in Rstudio.

## Reference
Martínez, M. R., Corradin, A., Klein, U., Álvarez, M. J., Toffolo, G. M., di Camillo, B., … Stolovitzky, G. A. (2012). Quantitative modeling of the terminal differentiation of B-cells and mechanisms of lymphomagenesis. Proceedings of the National Academy of Sciences, 109(7), 2672–2677.
